## 向量、基与坐标

| 符号                                      | 含义与限制                                                                  |
| ----------------------------------------- | --------------------------------------------------------------------------- |
| `\mathbf x,\mathbf v\in\mathbb R^n`       | 默认列向量；正文横向列出分量时保留转置上标 `\mathsf T`                      |
| `\mathbf0`                                | 由上下文确定维数的零向量；不能作为基向量或特征向量                          |
| `\operatorname{span}(\mathbf v_1,\ldots)` | 全部线性组合；生成集可冗余，基必须同时线性无关并张成目标空间                |
| `B=(\mathbf b_1,\ldots,\mathbf b_n)`      | 有序基；基向量顺序会改变坐标列                                              |
| `[\mathbf x]_B`                           | 向量 `\mathbf x` 在基 `B` 下的坐标，而不是另一个向量                        |
| `P_B=[\mathbf b_1\ \cdots\ \mathbf b_n]`  | 基向量用标准坐标组成的列矩阵，满足 `[\mathbf x]_{\rm std}=P_B[\mathbf x]_B` |

欧氏内积写作 `\langle\mathbf x,\mathbf y\rangle=\mathbf x^\mathsf T\mathbf y`。长度、夹角和正交性依赖所选内积；线性相关、张成与维数只依赖线性结构。非正交基下，坐标分量平方和一般不等于向量长度平方。

## 矩阵、方程组与子空间

| 符号                                   | 含义与限制                                                                             |
| -------------------------------------- | -------------------------------------------------------------------------------------- |
| `A\in\mathbb R^{m\times n}`            | `m` 行 `n` 列，把 `\mathbb R^n` 的列向量映到 `\mathbb R^m`                             |
| `A=[\mathbf a_1\ \cdots\ \mathbf a_n]` | `A\mathbf x` 是列向量 `\mathbf a_j` 按坐标 `x_j` 的线性组合                            |
| `[A\mid\mathbf b]`                     | 方程组 `A\mathbf x=\mathbf b` 的增广矩阵；行变换保持解集，不表示列空间中的同一线性映射 |
| `\operatorname{rref}(A)`               | 简化行阶梯形；主元列与自由变量按未知量列位置识别                                       |
| `\operatorname{rank}(A)`               | 主元个数，也等于列空间和行空间的维数                                                   |
| `\ker A` 或 `\mathcal N(A)`            | 零空间 `\{\mathbf x:A\mathbf x=\mathbf0\}`，是 `\mathbb R^n` 的子空间                  |
| `\operatorname{Col}(A)`                | `A` 的列空间；`A\mathbf x=\mathbf b` 相容当且仅当 `\mathbf b\in\operatorname{Col}(A)`  |

非齐次相容方程组的全部解写成 `\mathbf x=\mathbf x_p+\mathbf z`，其中 `\mathbf z\in\ker A`。对 `A\in\mathbb R^{m\times n}`，秩—零化度为

$$
\operatorname{rank}(A)+\dim\ker A=n.
$$

最小二乘解最小化 `\lVert A\mathbf x-\mathbf b\rVert_2`，满足正规方程 `A^\mathsf TA\widehat{\mathbf x}=A^\mathsf T\mathbf b`。只有当 `A` 满列秩时解才唯一且可写成 `(A^\mathsf TA)^{-1}A^\mathsf T\mathbf b`；数值计算优先 QR 或 SVD，不把显式形成正规方程当作通用稳定算法。

## 行列式与线性映射

行列式只对方阵定义。`\det A` 是有向体积倍率；`|\det A|` 是普通体积倍率。交换两行变号、某行乘 `c` 使行列式乘 `c`、一行加另一行倍数不改变行列式。乘法满足 `\det(AB)=\det A\det B`，因此方阵可逆、行列式非零、满秩、零空间平凡和对每个右端项有唯一解属于同一等价链，但每次引用须说明已建立的前提。

线性映射写作 `T:V\to W`，核与像分别记 `\ker T`、`\operatorname{im}T`。有限维时

$$
\dim V=\dim\ker T+\dim\operatorname{im}T.
$$

若输入基为 `B`、输出基为 `C`，矩阵记为 `[T]_{C\leftarrow B}`，满足

$$
[T\mathbf x]_C=[T]_{C\leftarrow B}[\mathbf x]_B.
$$

对同一空间上的算子，基从 `B` 换到 `C` 时得到相似矩阵；正文必须先定义换基矩阵的方向，再写 `S^{-1}AS`，不能只凭记忆交换次序。

## 特征结构、谱定理与二次型

特征向量必须非零，并满足 `A\mathbf v=\lambda\mathbf v`。特征空间是 `\ker(A-\lambda I)`；代数重数来自特征多项式，几何重数是特征空间维数。矩阵可对角化当且仅当存在一组由特征向量构成的基；“有 `n` 个计重特征值”本身不足以保证可对角化。

实矩阵可能只有复特征值。正文若限制在实向量空间，必须明确说明复根需要扩域。实对称矩阵使用谱定理：存在正交矩阵 `Q` 和实对角矩阵 `\Lambda` 使 `A=Q\Lambda Q^\mathsf T`。二次型写成 `q(\mathbf x)=\mathbf x^\mathsf TA\mathbf x`，其中只对称部分影响数值；正定等价于实对称矩阵的全部特征值为正。

## 数值核验与练习

- 手算消元必须展示行操作或可复核的等价矩阵，并把主元列、自由变量和原矩阵列空间区分开。
- 逆矩阵、行列式、特征值和正规方程的例题至少用代回、迹/行列式、正交残差或矩阵乘法中的一种独立核验。
- 浮点计算使用容差判断近零，不把显示为 `0.0000` 当作精确为零；病态矩阵、近线性相关和正规方程的条件数放大须注明。
- 物理或数据例题必须说明分量单位和缩放；不同单位的坐标不能未经建模直接使用欧氏距离。
- 每章练习同时覆盖概念条件、可复算计算与迁移应用；每题含 `topic`、`difficulty`、`hint` 和紧邻 `Solution`。
