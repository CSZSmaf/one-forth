# One Forth 科学审阅制度

## 1. 状态语义

科学检查与内容成熟度分开记录。`checked` 表示作者自检或自动化检查已经执行，不表示独立同行审阅。

```yaml
review:
  editorialStatus: draft
  mathematicalStatus: checked
  numericalStatus: checked
  sourceStatus: checked
  accessibilityStatus: pending
  humanReviewer: null
```

- `pending`：没有足够证据。
- `checked`：存在可追溯的自动测试、复算记录或作者检查。
- `humanReviewer`：只填写真实身份与审阅记录引用；自动化代理不得填写自己或虚构姓名。

## 2. 正文检查清单

每篇完整正文逐项记录：

1. 定义含对象、条件、量词和适用域。
2. 符号先声明后使用，命名空间和单位明确。
3. 定理和命题列出全部假设。
4. 推导每一步注明代数、定义、定理或近似依据。
5. 结论写明适用范围、反例或失败条件。
6. 例题数值以独立脚本或手算复核。
7. 练习答案代回、反算或由测试验证。
8. 物理量维度一致，输入、坐标和输出写单位。
9. 图形与公式使用同一参数、坐标约定和数据。
10. 动画只作为观察证据，不充当证明。
11. 理论结论、数值近似和经验观察明确区分。
12. 前沿或有争议结论标明不确定性和日期。
13. 来源优先出版社、DOI、arXiv、作者页、官方仓库和权威教材。
14. 引用紧邻所支持的陈述，并逐字段核对元数据。
15. 不把相关性写成因果，不把玩具实验推广到未验证场景。

## 3. 数值实验验证记录

每个实验必须提供：

- 观察目标；
- 数学模型与符号；
- 假设、初边值条件和适用范围；
- 参数范围、单位和固定种子；
- 操作步骤与预期现象；
- 解析基线、有限差分、不变量或收敛测试；
- 误差定义、容差和测试环境；
- 失败、取消、超时和过期结果处理；
- 局限与不得外推的结论；
- 相关正文和首次定义链接。

纯模型测试优先放入 `packages/math-core`、`packages/numerical`、`packages/physics` 或独立模型模块。React 组件测试只验证状态和呈现，不替代数值正确性测试。

## 4. 八个实验的最低证据

| 实验         | 最低验证                                                               |
| ------------ | ---------------------------------------------------------------------- |
| 二维线性变换 | 单位、旋转、缩放、剪切、反射、秩一投影、零矩阵；行列式、有向面积和方向 |
| 方向导数     | 单位方向、梯度点积、中心差分误差、梯度向量与标量方向导数区分           |
| 梯度下降     | 二次函数解析最优点、稳定/临界/发散步长、动量、轨迹与损失一致           |
| 反向传播     | 前向、局部导数、上游与累积梯度；有限差分相对误差                       |
| 决策边界     | 固定种子、取消与过期隔离、当前模型指标、发散状态、玩具数据边界         |
| 一维波动方程 | 方程、区间、初位移/速度、边界、单位、解析/离散方法、稳定或误差测试     |
| 傅里叶叠加   | 系数、奇偶性、部分和、频率、周期和 Gibbs 现象陈述                      |
| 注意力矩阵   | Q/K/V、logits、缩放、mask、softmax、输出；行和、掩码和维度不变量       |

## 5. 来源与可复现性

- 外链记录 `verifiedAt`，HTTP 可达不等于支持正文主张。
- 随机结果保存种子；URL 反序列化运行时校验并限制范围。
- 报告记录实际命令、通过数、失败数和容差。没有运行的测试保持 `pending`。
