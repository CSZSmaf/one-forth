## 共同符号

| 符号        | 本册含义                       | 使用约束                                                 |
| ----------- | ------------------------------ | -------------------------------------------------------- |
| $x,y$       | 实变量或平面坐标               | 默认取实数；其他数域必须显式声明                         |
| $D$         | 表达式或函数的实定义域         | 先于约分、平方、开方和对数变形写出                       |
| $S$         | 方程或不等式的解集             | 只包含通过原问题定义域与代回检查的元素                   |
| $p(x),q(x)$ | 实系数多项式                   | 有理式 $p/q$ 还要求 $q(x)\ne0$                           |
| $f:X\to Y$  | 从定义域 $X$ 到陪域 $Y$ 的函数 | 值域写为 $f(X)$，不得与陪域混用                          |
| $a$         | 指数或对数的底数               | 实函数语境固定 $a>0$ 且 $a\ne1$                          |
| $P=(x,y)$   | 平面上的点                     | 点、方向向量和法向量在首次使用时区分                     |
| $t$         | 参数或带单位的时间             | 几何参数给出取值区间；物理时间显式写单位，指数必须无量纲 |
| $e$         | 圆锥曲线离心率                 | $e>0$；$e<1,e=1,e>1$ 分别对应非退化椭圆、抛物线、双曲线  |

## 术语边界

- 表达式给出一个量；方程要求等式成立的输入；恒等式在共同定义域内处处成立。
- 双向等价变形保持解集。只有单向推出关系的平方、乘以可能为零的式子等操作产生候选集合，候选必须回到原式检验。
- 多项式的根与对应多项式函数的零点一致；有理函数的零点还必须避开分母零点。
- 约去共同因式只化简定义域内的函数值，不能补回原式的排除点。
- 函数由定义域、陪域和对应规则共同确定。值域是实际输出集合，不自动等于陪域。
- $f^{-1}$ 表示反函数，$1/f$ 表示函数值的倒数；二者的存在条件和定义域不同。
- 参数方程除曲线点集外还保留参数范围、遍历方向和覆盖次数。消去参数后必须补回这些限制。

## 结果检查顺序

1. 检查原问题定义域、参数范围和单位。
2. 标记每一步是等价变形还是候选变形。
3. 代回原式复核候选根、端点和排除点。
4. 用符号区间、图像交点、判别式或距离定义做第二条独立检查。
5. 含参数问题单独计算临界参数；含单位的指数与对数先核对无量纲条件。
