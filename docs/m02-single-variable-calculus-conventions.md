## 数列、极限与级数

| 符号          | 含义与限制                                                            |
| ------------- | --------------------------------------------------------------------- |
| `n,k,N`       | 正整数指标；阈值写作 `N\in\mathbb N^+`，求和指标通常用 `k`            |
| `a_n`         | 数列第 `n` 项；数列本身写作 `(a_n)` 或 `(a_n)_{n\ge 1}`               |
| `L`           | 有限实数极限；定义中写 `\lim_{n\to\infty}a_n=L`                       |
| `\varepsilon` | 任意给定的正误差，始终声明 `\varepsilon>0`                            |
| `s_n`         | 级数的第 `n` 个部分和，`s_n=\sum_{k=1}^n a_k`                         |
| `S`           | 部分和数列的有限极限；仅当 `s_n\to S` 时写 `\sum_{k=1}^{\infty}a_k=S` |

“数列”指映射 `n\mapsto a_n`；“级数”指部分和数列的收敛问题。无穷项相加不得写成已经完成的有限运算。发散只表示不存在有限极限，不等同于趋向正无穷。

## 函数极限、导数与微分

| 符号         | 含义与限制                                                      |
| ------------ | --------------------------------------------------------------- |
| `x`          | 自变量；讨论 `x\to a` 时，`x` 可位于穿孔邻域且不要求等于 `a`    |
| `a`          | 固定的极限点或展开中心；与数列项 `a_n` 同章出现时必须用文字区分 |
| `\delta`     | 输入邻域半径，取正数，并允许依赖 `\varepsilon`                  |
| `h`          | 输入增量；差商中要求 `h\ne0`，取极限时 `h\to0`                  |
| `f'(a)`      | `f` 在 `a` 的导数，只有差商极限存在且为有限数时定义             |
| `\Delta y`   | 实际函数增量 `f(a+h)-f(a)`                                      |
| `\mathrm dy` | 线性主部 `f'(a)\,\mathrm dx`；在一元情形取 `\mathrm dx=h`       |
| `P_n(x)`     | `n` 次 Taylor 多项式；余项单独写作 `R_n(x)`                     |

“可导”蕴含“连续”，逆命题不成立。微分表示局部线性映射，不把 `\mathrm dx` 和 `\mathrm dy` 在所有公式中当作可任意约分的普通实数。Taylor 多项式是有限阶近似；只有另行证明收敛与函数相等时，才把 Taylor 级数当作函数表示。

## 定积分与累积

| 符号                        | 含义与限制                                                                  |
| --------------------------- | --------------------------------------------------------------------------- |
| `P`                         | 分割 `a=x_0<x_1<\cdots<x_n=b`                                               |
| `\Delta x_i`                | 第 `i` 个子区间宽度 `x_i-x_{i-1}>0`                                         |
| `\xi_i`                     | 第 `i` 个子区间中的取样点                                                   |
| `\lVert P\rVert`            | 分割范数 `\max_i\Delta x_i`                                                 |
| `\int_a^b f(x)\,\mathrm dx` | 有向定积分；上下限和积分变量必须明确                                        |
| `F`                         | 原函数或累积函数；使用前说明是 `F'=f` 还是 `F(x)=\int_a^x f(t)\,\mathrm dt` |
| `C`                         | 不定积分中的任意实常数                                                      |

定积分是数值，原函数是函数族。净累积保留符号；几何面积对负值区段取绝对值后分段积分。反常积分先写成有限区间积分的极限，只有该极限有限时才称收敛。

## 单位与数值核验

- 自变量带单位时，导数单位为“函数值单位/自变量单位”，定积分单位为二者乘积。
- 对数、指数和幂级数的自变量若来自物理量，先除以同单位参考量形成无量纲比值。
- 数值近似同时写明步长或截断阶数；不得用有限小数图像代替收敛证明。
