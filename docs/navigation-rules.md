# One Forth 导航规则

## 1. 全局导航

桌面端固定为：

```text
One Forth | 教材目录 | 搜索 | 工具 | 主题切换
```

三个文字入口为教材目录、搜索、工具。工具菜单收纳学科浏览、知识图谱、实验室、专题路线、术语、符号、公式和资源。移动端只显示 Logo、搜索和目录按钮。

## 2. 唯一明显下一步

- 首页：无记录时“从《数学语言、集合与证明》开始”，有记录时“继续：分册 · 章节”。
- 教材库：进入某一册，不并列推荐多条路径。
- 分册页：“开始本册”或“继续本册”。
- 章节页：底部“下一章”为最明显操作；上一章权重次之。
- 实验页：返回主要教材章节。

同一区域不得出现多个同等级主按钮。

## 3. 首页

首页最多四个主要区域：

1. 简短说明与搜索。
2. 一个开始/继续状态。
3. 教材总目录开头。
4. 项目说明与贡献。

学习路径列表、精选文章、实验列表、图谱预览、资源长列表、最近更新和背景数学交互从首页移走。最近更新使用 `/updates`。

## 4. 教材页

- `/books` 先显示三个系列和分册，不默认展开数百章。
- Book 页以连续目录显示 Part 和 Chapter，不使用大卡片墙。
- 状态用文本和小图标表达，不只依赖颜色。
- 每册只有一个开始/继续动作。

## 5. 章节页

- 桌面：左侧当前分册目录、中间正文、右侧本页 H2/H3。
- 左侧默认只展开当前 Part；其他 Part 只显示折叠标题。
- 正文顶部固定为面包屑、章节编号、标题、摘要、预备知识、学习目标。
- 正文底部固定为小结、练习、参考资料、相关章节、上一章/下一章。
- 相关链接、图谱和推荐内容不得压过线性阅读操作。

## 6. 移动端与无障碍

- 教材目录进入有焦点管理的抽屉；本页目录进入独立下拉面板。
- 当前章使用 `aria-current="page"`，当前页内标题使用 `aria-current="location"`。
- 抽屉支持键盘、Escape 关闭并恢复触发器焦点。
- 锚点跳转后目标可聚焦且不被粘性标题遮挡。
- 公式、表格、代码只允许局部滚动，禁止页面级横向溢出。
- 200% 缩放和 reduced motion 下仍保留顺序与含义。

## 7. 导航审计

`audit:navigation` 应输出首页区域、可见入口、主/次级动作、重复目标和旧 URL 处理。验收上限：桌面主导航不超过三个文字入口，首页主要区域不超过四个，单一区域只有一个主操作。
