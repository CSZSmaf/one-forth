# One Forth 设计系统

本文记录界面语义、排版与交互约束，实际实现以组件和样式源码为准。

本文件以当前 `apps/web/app/globals.css`、`apps/web/app/[locale]/design-system/page.tsx`、通用控件、文章、路径、图谱和交互实验组件为事实来源。文中“已实现”描述当前代码；“后续项”不得在验收、截图或发布说明中当作现有能力。

## 1. 设计定位

One Forth 的视觉方向是：

> 当代科学出版物、大学教材、研究型数字档案和交互式数学实验室的结合。

视觉成熟度来自精确排版、稳定网格、清晰信息秩序、克制颜色、一致图形语言和细致反馈，而不是卡片数量、圆角、阴影、渐变或动画。

当前公开站点以教材课程树为主入口。2026-09-09 的视觉升级采用纸白与墨色、宋体风格标题、连续目录和非对称首页。具体实现与真实验收状态分别记录在本文和 `docs/progress-log.md`；设计 token 或页面截图不能代替功能验收。

## 2. 核心原则

1. **内容优先**：正文、公式、图和实验是视觉中心。
2. **连续画布**：优先通过排版、间距、细线、背景明度和结构位置分区。
3. **出版式秩序**：定义、定理、证明、图、表和方程有统一编号及节奏。
4. **语义颜色**：颜色表达领域、数学对象或状态，不作背景装饰。
5. **可解释交互**：参数变化同时显示数值、单位和解释。
6. **无障碍默认**：键盘、焦点、对比度、reduced motion 和文本替代不是后补功能。
7. **跨页面一致**：同类页面共享正文宽度、网格、对齐和数学对象颜色。

## 3. 严格禁止

- 卡片嵌套卡片、普通段落卡片化、每个参数一个卡片。
- 大量同尺寸卡片墙和模板化三列卖点。
- SaaS Dashboard 首页、价格方案、用户评价、虚假统计和机构背书。
- 玻璃拟态、高饱和渐变、霓虹描边、无语义发光。
- 随机光斑、漂浮粒子、装饰性科技网格和无功能背景动画。
- 所有按钮药丸化、到处使用胶囊标签。
- 普通正文和工具面板使用重阴影。
- 依靠圆角、阴影或超大留白制造层级。
- 大幅缩放、弹跳和过冲作为默认动效。
- 装饰性 3D 或为了“高级感”牺牲可读性。
- 随机改变向量、梯度、场、波函数等数学对象颜色。

删除阴影和圆角后，页面结构仍必须成立。

## 4. 表面层级

已实现表面直接映射到真实 token：

```text
Level 0  页面画布                         --canvas
Level 1  正文、连续章节、普通工作区       --surface
Level 2  控件底、实验画布、浮起区域       --surface-raised / --surface-subtle
Level 3  对话框、抽屉、搜索浮层           --surface-raised + --shadow-modal
```

- 同一区域最多两层可见容器嵌套；正文与路径列表主要靠排版、分隔线和留白建立层级。
- `--shadow-overlay` 只用于移动导航等真实浮层，`--shadow-modal` 用于搜索、对话框和抽屉。
- 普通文章、路径节点、语义块和实验外壳没有卡片阴影。
- 旧文档中的 surface/text/focus 语义别名并未实现；不得从历史规范复制名称，必须使用本节列出的真实 token。

## 7. 网格与阅读宽度

- 页面宽度上限 `1360px`，页边距 `clamp(20px, 3.4vw, 48px)`；≤620px 固定为 20px。
- 首页在 >980px 使用 `1.65fr / 1fr` 的题名搜索与阅读入口两栏；≤980px 阅读入口放在题名和搜索之后；≤620px 所有入口按文档顺序排列。
- 文章桌面使用 `minmax(170px, 200px) minmax(0, 720px) minmax(150px, 190px)`，间隔 `clamp(24px, 2.5vw, 36px)`。
- ≤1160px 隐藏文章右侧目录，保留左侧教材目录与正文；≤900px 使用单栏和现有教材目录抽屉；≤620px 学习状态及实验面板堆叠。
- 教材目录用系列 / 分册 / 章节编号形成层级。分册索引桌面为两列连续列表；手机单列。
- 搜索左栏 210px；图谱左栏 228px；实验参数栏 250px。各自使用现有响应式断点，避免在小屏压缩正文或数学画布。

## 9. 页面模式

### 首页

首页只有四个主区块：题名与学习入口、系列总目录、首册章节目录、作者信息。题名左侧包括品牌、内容定位、简介和真实搜索表单；右侧为唯一的开始或继续阅读入口。它们共享连续画布，仅用细线明确分界。

- 标题桌面约 48px，手机 32px；首屏必须露出下一目录区块。
- 系列 / 分册 / 编 / 章节统计来自公开课程仓库，使用紧凑的四项信息行；不增加营销统计。
- 系列和首册章节使用编号、题名、摘要与阅读链接，目录规模和链接均由内容数据生成。
- 开始 / 继续阅读沿用 `HomeCurriculumAction` 和浏览器学习状态，不改变存储格式或恢复锚点。
- 不在首页加入图谱、实验或新路由作为平行主入口。已有工具通过导航访问，数学图形不是首页装饰。
- 首页新增文字通过 `uiText[locale].textbookHome` 管理，品牌和个人资料读取 `siteConfig`。

### 文章页

文章由左侧教材目录、中间正文和右侧页内目录组成；页面宽度见上一节。当前章节有边线、背景和文字强调，颜色不是唯一提示。

- 题头依次呈现教材位置、章节编号、题名、摘要、元信息、预备知识和学习目标。报告错误链接属于元信息行。
- 学习位置、章节状态和完成按钮在桌面形成紧凑的两列区，手机按阅读顺序排列；本册完成进度独占一行。
- 正文 H2 有细分隔线，定义 / 定理 / 证明 / 例题 / 练习保留语义块与编号，宋体题名和无衬线标签职责分明。
- 学习状态、练习完成、锚点复制与恢复、前后章节、书目及公开内容规则沿用原实现。
- 数学公式、代码及表格使用局部滚动；不缩小公式或隐藏溢出的内容。

### 学习路径页

- 路径题名区显示预计小时、概念数、受众和本地完成进度。
- 概览区并列先修与阶段目标；学习序列是带编号的连续列表，明确区分“正文”和“大纲”。
- 每个概念状态为“未开始 / 进行中 / 已完成”，与文章状态共享同一 localStorage 数据。
- 路径百分比只按已完成概念数计算：`completed / total`；进行中的文章不计为完成。
- 路径后续为阶段检查、综合练习和下一路径/图谱入口。当前检查点与综合练习是内容展示，还没有独立的完成状态。

### 图谱页

- `228px + 画布` 两栏，最小高度 `700px`；控制区提供搜索、关系类型、最高难度、学科图例和当前可见关系类型图例（线型与颜色取自注册表，颜色不作唯一编码）。
- 继续使用现有公开图谱投影与筛选规则，保持节点布局、关系算法、URL 状态与触屏选择行为一致。
- 节点坐标来自构建期确定性布局（`generated-graph-layout.ts`），缺失时回退黄金角螺旋；画布支持 `55%–180%` 缩放、背景拖动平移、重置、节点拖动、焦点选中、关系箭头和当前节点详情。
- 可见标签按“选中 > 邻居 > 高度数”贪心防撞；SVG 提供 `<title>`、`<desc>` 与动态 `aria-label`；画布下方提供文本摘要和可展开节点列表。
- 移动端控制区、选择详情和节点列表改为单栏，toolbar 进入正常文档流；SVG 保留纵向页面滚动能力。

### 搜索

- header 搜索触发器和独立搜索页使用同一索引语义；浮层宽度最多 `720px`。
- 浮层结果用 `aria-selected` 与 `--accent-soft` 标记当前项，显示结果类型、题名和摘要。
- 筛选器使用紧凑 select，不使用胶囊标签墙；空状态提供文字建议和链接。
- 搜索、dialog 和 drawer 使用 Radix Dialog 管理焦点并返回触发器；overlay 是实际悬浮层，因此允许 modal shadow。

## 10. 语义块

`SemanticBlock` 已实现 `intuition`、`definition`、`theorem`、`lemma`、`proof`、`derivation`、`example`、`counterexample`、`misconception`、`callout`、`exercise` 和 `checkpoint`。它们共享连续正文、左侧细线、标题和可选编号，不使用嵌套卡片。

- **Intuition**：使用数学学科色和轻量横向淡化背景；文案必须明确其解释作用，不能替代证明。
- **Theorem**：上下强边界、无左边界，强调条件与结论。
- **Proof**：点状左边界并自动显示结尾方框；当前不是折叠块。
- **Misconception**：使用 `--warning` 左边界，不铺大面积红色。
- **Exercise**：使用 `--success`，带“标记完成 / 已完成”的 `aria-pressed` 按钮；完成状态按页面路径与练习 ID 单独保存在 localStorage，不改变文章完成状态。
- **Solution**：使用原生 `<details>`，默认折叠，summary 为“查看解答”。
- **ResourceCard**：从集中资源注册表读取类型、年份、题名、作者、价值和官方来源；缺失 ID 显示明确错误文本。
- **Equation / Symbol**：公式有 figure/figcaption 语义，符号通过 `role="definition"` 提供含义与单位。

练习完成状态是第二轮已实现能力；路径页的“综合练习”目前仍是静态路径内容，两者不得混淆。

## 11. 控件

### 已实现状态

- **Button**：`.button` 为透明 secondary，`.button-primary` 为深色主操作，`.icon-button` 为 `44×44px`；disabled 使用 `opacity: 0.52` 和 `not-allowed`。当前没有独立 destructive 或 loading button variant。
- **Input / Select**：`.ui-input`、`.ui-select` 高 `44px`，常驻 label，hover 将边界从 subtle 提升到 strong；全局 `:focus-visible` 使用 `2px` accent outline。
- **Range**：控件盒高 `24px`，轨道高 `3px`，WebKit thumb 为 `16px`、Firefox thumb 为 `14px`；标签、当前值和步长由组件显式提供。轨道上的低对比线性渐变表达可操作范围，属于功能编码而非装饰渐变。
- **Checkbox**：原生 input 保留语义并视觉隐藏，20px 自定义方框显示 check；checked 同时使用图标、背景和边界，不只靠颜色。
- **Tabs**：`role="tablist"`、`role="tab"`、`aria-selected` 和关联 panel 已实现；选中态使用 accent 下边界。
- **Segmented control**：`aria-pressed` 表达状态，选中态使用 `--accent-soft` 与 `--accent-ink`。
- **Details / accordion / Solution**：保留原生 summary 与键盘行为。
- **Dialog / Drawer**：使用 Radix Dialog，具有 overlay、焦点约束、Escape/关闭按钮和关闭后焦点返回。
- **Tooltip**：hover 与 focus-visible 都可触发；仅用于补充信息，不承载唯一关键指令。
- **进度与状态**：文章、路径、实验均提供文字、图标或数值，并带 `progressbar`/`progress` 语义。

### 禁止与后续项

- 禁止直接把未样式化浏览器默认按钮、输入、选择器或 range 作为最终产品控件。
- 设计系统概念检查中的 radio 目前仍使用原生外观；它是待补齐样例，不得复制为生产标准。
- 表单错误、成功、只读、必填说明和 destructive/loading button 尚无完整共享 variant，是后续项。
- 实验分享、导出、播放和参数按钮在桌面与手机都至少 `44px` 高，移动端操作按钮至少 `44×44px`；所有拖拽还要有键盘或数值输入替代。

## 12. 实验视觉

`InteractiveFigure` 只通过注册 ID 从 MDX 引用，文章不直接 import 某个实验实现。统一外壳已经包含：

```text
实验类型、题名、说明                 分享状态 / SVG / PNG / 全屏
主画布                               250px 参数区
后退 / 播放暂停 / 前进 / 重置         进度 / 步骤 / 0.25–2× 速度
可选指标

```

- 外壳在文章正文流内宽 `100%`、上下 margin `2.5em`，当前受 `--content-max: 720px` 约束；尚未实现宽于正文的 figure breakout。
- 桌面工作区为 `minmax(0, 1fr) 250px`，最小高度 `390px`；画布是视觉中心，参数区独立滚动。
- `≤620px` 时画布和参数区上下堆叠，画布最小高度 `300px`，timeline、transport 和指标重排。
- 参数使用 label、范围、数值、单位、预设、矩阵单元与重置组织；颜色之外必须有数字、文字、形状或线型。
- `Suspense` loading 与 error boundary 已实现，二者最小高度 `300px`；错误使用 `role="alert"` 并提供重试。
- `neural-decision-boundary` 额外实现 training、completed、cancelled、diverged 与 Worker 进度；这些训练状态不是所有实验自动拥有的通用能力。
- 分享把序列化状态写入 URL 并尝试复制；SVG/PNG 按 adapter 导出；全屏使用 Fullscreen API。导出失败通过 aria-live 状态反馈，不保留无响应按钮。

内容与实验必须形成“问题—操作—结论”关系：MDX 在图前写观察目标，在图后写操作任务、可复算结论和边界。图形不能替代定义、推导或证明。

## 13. 动效

### 已实现

- 普通反馈使用 `120ms`，进度与常规状态使用 `180ms`，dialog/drawer 使用 `180ms`；没有 spring、弹跳或过冲。
- tooltip 只有 `4px` 进入位移；dialog 为 `10px`，drawer 为 `18px`。禁止增加大幅缩放、视差和装饰性背景动画。
- 每个正式实验提供播放/暂停、前后单步、重置、速度和进度；键盘为空格、左右方向键和 Home。
- 浏览器标签进入 hidden 状态时，`visibilitychange` 会暂停播放。
- `VisualizationFrame` 使用 `IntersectionObserver`，阈值为 `0.05`；实验离开视口后调用 `pause()`，实现离屏暂停。
- `prefers-reduced-motion: reduce` 会把三个 motion token、全部 animation 和 transition 降到 `0.01ms`，关闭 smooth scroll，并限制 animation iteration 为一次。
- playback 同时监听 reduced-motion；偏好开启时立即停止自动播放，播放操作改为直接跳到起点或终点，信息仍可通过单步、参数、数值和文本替代读取。

### 约束

- 首页数学图形只由用户操作参数，不允许自动漂移、粒子、发光或无功能循环动画。
- 动画不得造成布局抖动；loading/error 使用固定最小工作区。
- 新 rAF、timeout、Worker、IntersectionObserver、事件监听与全屏监听必须在卸载时清理。

## 14. 响应式与触摸

主要实现断点为 `1160px`、`980px`（首页）、`900px` 和 `620px`；视觉验收仍至少覆盖 `390px`、`768px`、`1440px`。

- `1160px`：文章右栏折叠，正文内目录出现。
- `900px`：header 切换移动导航，文章、搜索和图谱转为紧凑或单栏布局。
- `620px`：gutter 与字号固定到移动值，路径、文章状态、实验工作台、设计系统样例和 footer 全部堆叠。
- 图谱 SVG 使用 `touch-action: pan-y`，不能拦截页面纵向滚动；节点拖动仍须保留可聚焦链接与列表替代。
- 交互图的拖拽对象必须同时提供键盘或数值输入；hover 信息必须有 focus/tap 等价入口。
- 公式、代码和表格只在局部容器滚动，不允许页面级横向溢出。

## 2026-10-25 书架与目录实施规范

首页教材区采用四个学科入口，用竖线分隔，不展开书籍或章节。手机端按可用宽度排列入口，保持清晰的阅读顺序。学科页和完整书架使用直角封面、册号、书名和学科色识别书籍，封面属于书籍实体展示，不添加嵌套内容卡片、阴影或立体翻转。封面展示与章节目录分开设计。

分册采用封面与紧凑目录并列：编标题清晰分组，章节编号左对齐，宋体章节名称与细引导线构成连续目录，不重复章节简介，不显示虚构页码。手机端缩小封面并将目录提前；正文侧栏显示全部章名和章号，保留收展与焦点控制。

## 2026-10-25 参考资料与公式

资源目录优先展示课程，并为每项资源提供直接来源入口。分册参考资料从章节的实际引用汇总，避免重复链接；机构、作者、版本与访问日期以官方页面为准。

行内公式、控件标签、指标和图内公式使用 packages/ui 的数学展示组件。公式保留变量大小写、上下标和单位，不继承英文标签的大写与字距样式。控件保留文本可访问名称；溢出公式支持局部滚动和键盘聚焦。图内文字说明采用混合数学标注，相邻标注可错行排列。SVG 与 PNG 导出保留明确的原生文本等价项。

公开修订摘要仅说明读者需要的内容变化，排除编辑指令、本地路径、部署信息及个人资料。样式与元数据迁移记录不进入公开修订索引。
