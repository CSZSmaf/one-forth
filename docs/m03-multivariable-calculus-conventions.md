## 空间、映射与微分

| 符号                                | 含义与限制                                                                                                     |
| ----------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| `\mathbf x,\mathbf h\in\mathbb R^n` | 点或增量向量；二维坐标可写 `(x,y)`，三维坐标可写 `(x,y,z)`                                                     |
| `\lVert\mathbf x\rVert`             | 标准欧氏范数；若使用其他范数或度量必须另行声明                                                                 |
| `B_r(\mathbf a)`                    | 开球 `\{\mathbf x:\lVert\mathbf x-\mathbf a\rVert<r\}`；极限使用穿孔邻域时排除 `\mathbf a`                     |
| `f:\mathbb R^n\to\mathbb R`         | 标量场；输出带单位时，梯度各分量使用“输出单位/对应坐标单位”                                                    |
| `F:\mathbb R^n\to\mathbb R^m`       | 向量值映射或向量场；输入、输出维数必须在矩阵公式附近可见                                                       |
| `Df(\mathbf a)`                     | 从输入增量到标量增量的线性映射；列梯度约定下 `Df(\mathbf a)[\mathbf h]=\nabla f(\mathbf a)^\mathsf T\mathbf h` |
| `J_F(\mathbf a)`                    | `m\times n` Jacobian，负责把输入增量映到输出增量；链式法则按映射复合顺序相乘                                   |
| `H_f(\mathbf a)`                    | 标量函数的 `n\times n` Hessian；只有在相应二阶偏导连续等条件下才直接使用对称性                                 |

多变量联合极限用 `\mathbf x\to\mathbf a` 表示。沿一条路径得到不同极限足以否定联合极限；若所有已试路径相同，仍不能据此证明联合极限存在。证明存在时应使用范数估计、夹逼、坐标变换或严格的序列判据。

方向导数默认方向 `\mathbf u` 为单位向量。若给定非单位向量，正文先归一化，或明确所求是沿参数速度向量的导数。梯度给出“最陡”方向的结论依赖选定的欧氏内积、无约束可行方向和一阶局部模型。

## 多重积分与变量替换

| 符号                                                   | 含义与限制                                                                              |
| ------------------------------------------------------ | --------------------------------------------------------------------------------------- |
| `D\subset\mathbb R^2`、`\Omega\subset\mathbb R^3`      | 二维、三维积分区域；边界和可测/可积条件随定理明确                                       |
| `\iint_D f\,\mathrm dA`、`\iiint_\Omega f\,\mathrm dV` | 标量累积；积分变量或坐标范围不能只靠图示推断                                            |
| `T:U\to D`                                             | 变量替换映射；正式换元公式要求适当的一一性、连续可微性与非退化 Jacobian，并处理边界例外 |
| `\lvert\det J_T\rvert`                                 | 体积缩放因子；绝对值不能因取向被省略                                                    |

连续函数在紧矩形或常见分片光滑有界区域上的积分可用累次积分计算。更一般情形交换积分次序必须引用适当的 Fubini/Tonelli 条件；不要从一两个良性例子推导“任何被积函数都可任意换序”。极坐标、柱坐标和球坐标的面积/体积元必须分别写出 `r`、`r`、`\rho^2\sin\varphi` 等 Jacobian 因子，并声明角度范围。

密度、质量、质心和转动惯量例题必须显式写单位。若坐标经过量纲缩放，Jacobian 同时携带相应单位，不把它当作纯数字。

## 曲线、曲面与取向

| 符号                                                                          | 含义与限制                                                     |
| ----------------------------------------------------------------------------- | -------------------------------------------------------------- |
| `\mathbf r:[a,b]\to\mathbb R^n`                                               | 分片 `C^1` 参数曲线；正则段要求 `\mathbf r'(t)\ne\mathbf0`     |
| `\mathrm ds=\lVert\mathbf r'(t)\rVert\,\mathrm dt`                            | 弧长元，与参数方向无关                                         |
| `\int_C \mathbf F\cdot\mathrm d\mathbf r`                                     | 向量场的功或环流积分；反向参数化会改变符号                     |
| `\mathbf X(u,v)`                                                              | 参数曲面；正则点要求 `\mathbf X_u\times\mathbf X_v\ne\mathbf0` |
| `\mathrm dS=\lVert\mathbf X_u\times\mathbf X_v\rVert\,\mathrm du\,\mathrm dv` | 无向面积元                                                     |
| `\mathbf n\,\mathrm dS`                                                       | 有向面积元；改变法向会改变通量符号                             |

标量线积分 `\int_C f\,\mathrm ds` 与向量场线积分 `\int_C\mathbf F\cdot\mathrm d\mathbf r` 分开命名。标量曲面积分与通量积分同样分开。保守场的路径无关结论必须带定义域条件；在有洞区域中仅有 `\nabla\times\mathbf F=0` 未必推出全局势函数存在。

## 向量微分算子与三大积分定理

对三维向量场 `\mathbf F=(P,Q,R)`，使用

$$
\operatorname{div}\mathbf F=\nabla\cdot\mathbf F,
\qquad
\operatorname{curl}\mathbf F=\nabla\times\mathbf F.
$$

- Green 定理默认平面区域边界按正向行进，使区域保持在左侧；单连通只是常用充分背景，实际条件按所用版本写明。
- Stokes 定理中曲面法向与边界方向遵循右手定则；更换曲面时必须保持同一条边界及一致取向，并确保场在覆盖区域的邻域内足够光滑。
- Gauss 定理使用闭曲面的外法向；若题目给内法向，应先转换符号。
- 场在区域内有奇点、区域有洞、边界不闭合或参数化退化时，先修正区域或分块，再决定能否应用定理。

证明框架可以说明分割、内部边界抵消和极限，但二维/三维图形或有限采样不作为定理证明。

## 数值核验与练习

- 例题至少保留一个直接计算核验和一个条件/取向核验；综合题应明确为什么选择某条积分定理比直接参数化更合适。
- 数值积分注明区域、网格/求积阶数和误差口径；有限采样相等不能替代恒等式证明。
- 所有角度约定为弧度；物理例题写明坐标与场分量的单位。
- 每章练习同时覆盖概念条件、可复算计算与迁移应用；答案核对边界、符号、维数、单位或数量级中的至少一项。
